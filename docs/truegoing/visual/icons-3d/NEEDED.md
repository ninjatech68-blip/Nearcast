# 3D icon export list

Source: 3dicons (open source, CC0) Figma community file. Export from Figma: select the icon, Export → PNG, 3x, transparent background. One colour style for the whole set (pick the one closest to Airbnb's matte-plastic look; the "Color" style is the usual choice). Save each file with the **exact filename in the first column** into this folder. Where 3dicons has no matching object, use the closest one and note it; the gap list at the bottom gets commissioned.

## After export

1. Drop the files in this folder (or in `ios/Resources/Icons3D/` once the `truegoing` repository exists).
2. Tell me which style you picked and which objects had no match.
3. I wire them: the app refers to icons by the filename stem, so no screen changes; the visual page picks them up on the next publish.

## Gap list, to commission if 3dicons has no match

Shuttlecock, cricket bat, carrom board, table-tennis paddle. Everything else in the set has a close object.
