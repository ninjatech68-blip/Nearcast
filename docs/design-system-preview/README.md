# Nearcast Design System Preview

This is a static review artifact for the approved Nearcast design system. It is not app implementation.

Open `index.html` directly in a browser, or serve the repository root and visit:

```text
http://127.0.0.1:4173/docs/design-system-preview/
```

Review goals:

- Verify light and dark semantic token behavior.
- Inspect real typography, spacing, radius, elevation, and focus states.
- Review component states before React Native implementation.
- Check responsive behavior across phone, tablet, and desktop widths.
