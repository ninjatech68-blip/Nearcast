# Nearcast Documentation Map

This folder is the master documentation set for the Nearcast mobile app project.

Nearcast helps a person broadcast an intent beyond a trusted closed group without exposing the group, faking activity, or losing control over who can respond.

## Document Groups

- Product direction: Product Requirements, First Version Requirements, Product Development Roadmap.
- User experience: User Journeys and Flows, Mobile App Design Foundation, Design System Specification, Writing and Content Guide, Mobile Screen Contracts.
- Trust and safety: Trust Privacy and Safety, Permissions and Access Rules, Community Policy Outline.
- Engineering: System Architecture, API Contracts, Implementation Guide, implementation plans.
- Operations: Metrics and Analytics Plan, Quality and Testing Plan, Release and Operations Plan.

## Naming Rule

Document names should be readable by a non-technical stakeholder. Prefer names like `Product Requirements` and `Trust Privacy and Safety` over internal abbreviations like `PRD`, `RLS`, or `MVP` unless the document itself explains the term.
